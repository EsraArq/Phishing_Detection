Phishing Detection Using Machine Learning
Comparative Analysis of Support Vector Machine (SVM) and Random Forest Classifier (RFC)
Project Overview
Phishing attacks remain a significant cybersecurity threat, targeting individuals and organizations through deceptive emails and social engineering techniques.
This research evaluates the effectiveness of two supervised machine learning algorithms, Support Vector Machine (SVM) and Random Forest Classifier (RFC), in identifying phishing emails.
Using Python and machine learning techniques, the study compares both models to assess their classification performance and potential applications in cybersecurity threat detection.
Research Objectives
- Develop machine learning models to classify phishing and legitimate emails.
- Compare the performance of SVM and Random Forest.
- Evaluate classification accuracy and model effectiveness.
- Explore how machine learning can support automated phishing detection.
Methodology
The research uses a labeled phishing email dataset and applies text preprocessing, TF-IDF feature extraction, and supervised machine learning.
The models are trained and evaluated using Python and scikit-learn.
Research Results
Support Vector Machine (SVM): 97.53% accuracy.
Random Forest Classifier (RFC): Approximately 93.07% accuracy.
The SVM model achieved higher classification accuracy on the evaluated dataset, suggesting that it was better suited to this particular classification task.
Technologies Used
Python, Jupyter Notebook, scikit-learn, Pandas, TF-IDF, Support Vector Machine, and Random Forest.
Future Improvements
Future development could include testing against newer phishing datasets, improving model generalization, and developing an interactive application that analyzes email content.
